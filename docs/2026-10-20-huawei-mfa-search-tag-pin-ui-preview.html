主题
标签样式

1 · 顶部三行合并为一行

账号数并入标题栏副标题；标签/置顶的 chips 收进「筛选」菜单；搜索、筛选、排序同处一行。

2 · 标签不抢验证码空间

验证码区保持现有 4:6 比例与自适应字号；置顶与标签都移到卡片右上角，不挤占验证码宽度。

3 · 一个入口承载视图与筛选

「筛选」按钮点开菜单：平铺 / 分组，全部 / 置顶 / 各标签；当前状态直接显示在按钮上。

置顶 + 标签：都放卡片右上角

当前采用 D：右上角一行右对齐，`#工作 置顶`；无标签只显示置顶，无置顶只显示标签。绝对定位，不改变验证码的 4:6 宽度与字号。

标签最大宽 80vp，超出省略；完整标签在详情/筛选/分组头可见。置顶保持纯文字，不与标签抢视觉。

A 用户名同行 / B 发行方色点 / C 第三行仍保留在顶部切换里，仅用于对比；实现只做 D。

实现提醒

标题从 30fp 调整为 22fp，以容纳“已保护 N 个账号”副标题；若真机标题栏高度不足，可把账号数只放在筛选菜单头部。

筛选菜单建议用 bindMenu + MenuItemGroup；分组态禁用拖拽；排序态强制回平铺并忽略置顶。

验证码区保持现有 4:6 比例与 50fp → 24fp 自适应字号，本次不调整；右上角一行高 16vp，位于验证码字形上方；标签最大宽 80vp，置顶为纯文字。
