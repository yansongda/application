# Changelog

本文件遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 规范，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [Unreleased]

### Added

- 首页新增搜索（发行方 / 用户名 / 标签）、标签筛选与按标签分组视图，列表上方由三行收敛为一行工具条
- 账号支持标签与置顶：标签/置顶保存在账号 config 中并随账号同步，列表项右上角展示
- 详情页新增「组织」卡片（标签 / 置顶），新增标签设置页；使用帮助补充组织方式说明

### Changed

- 本地存储收敛为单一 preferences 库 `mfa`（GSKV 模式，支持主应用与卡片提供方多进程并发读写）：安全设置改为逐字段 key（不再有 schema 版本号与整份 JSON，读写下沉到各自模型、去掉 `Store` 中间层）、卡片 formId 改为逐 key 存储，读写统一经 `utils/Prefs.ets`，用户可见行为无变化
- 环境地址改为由构建模式（debug/release）在编译期注入，移除 `module.json5` 中需手工解除注释的 `env` metadata，正式包不再有误连测试环境的可能
- 端内验证码计算改用 `@yansongda/otp` 库实现，替换自研 TOTP 算法；算法与输出不变（SHA1 + 6 位，仍与后端一致），用户可见行为无变化 (#173)
- 首页工具条与列表视图拆分为 `Toolbar` / `ListView` 两个组件，由 `Index` 统一编排；布局与交互不变
- 空态提示卡由独立组件 `IndexGuide` 内联进 `EmptyState`（删除该文件），页面级组件统一收在 `components/index/` 下；空态外观不变

### Fixed

- 修复应用锁已锁定或未登录时，卡片快捷入口可能越过门禁直接拉起扫码的问题

## [1.5.0] - 2026-10-05

### Added

- 新增 2*2 桌面服务卡片，展示已保护账号数，点一下即可跳转首页扫码添加 (#169)
- 新增「使用帮助」页，集中说明添加账号、使用卡片、多设备同步与安全机制 (#169)
- 首页列表点击验证码数字即可复制，详情页新增「复制验证码」按钮 (#169)
- 「我的」页新增「已保护 N 个账号」统计，以及「使用帮助」「关于（版本号）」入口 (#169)

### Changed

- 首页无账号时改为首屏直出扫码 / 手动输入入口与内嵌提示，不再展示全屏分步引导 (#169)
- 最低系统要求提升至 HarmonyOS 6.1.0(23)（桌面卡片依赖 API 23 状态管理 V2） (#169)

### Fixed

- 修复登录成功后需等待用户信息请求返回、网络较差时表现为「卡住」的问题 (#169)

## [1.4.0] - 2026-10-02

### Added

- 验证码改为端内离线计算，无需每次请求服务端，失败时自动回落服务端 (#135)
- 首页支持长按拖拽排序，完成后自动保存顺序 (#135)
- 首页无数据时增加 4 步使用引导 (#135)

### Changed

- 优化验证码倒计时与刷新，按实际周期实时更新，退后台暂停、回前台恢复 (#135)
- 合并发行方 / 用户名编辑页，统一编辑交互与空值兜底 (#135)
- 优化登录失败后的重试入口与注销后的登录态清理 (#135)

### Fixed

- 修复周期非 60 的约数或时区偏移非整小时时倒计时与验证码错位 (#135)
- 修复修改头像 / 昵称 / Slogan 后页面数据不刷新的问题 (#135)
- 修复创建时发行方 / 用户名含特殊字符导致 otpauth 链接错误 (#135)

### Security

- 敏感日志改为私密输出，避免登录凭证等信息落盘 (#135)
